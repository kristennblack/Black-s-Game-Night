# BLACK FAMILY GAME NIGHT
# MASTER PHASE W.15 DIRECTIVE
## Realistic Cosmetics Expansion + Home-Screen Cabin Navigation

Planning/build date: 2026-08-28
Status: Current add-on directive after W.14 approval
Depends on: W.14 realistic cabin rooms, W.13 room/catalog system, W.12 gameplay corrections, approved family-character locks

======================================================================
0. PURPOSE
======================================================================

The user approved the more realistic cabin-room direction and asked that the same quality bar be extended to the wearable/cosmetics system. The user also reported that the cabin is not currently reachable from the home screen. W.15 therefore locks two immediate requirements:

1. Add a prominent **Visit the Cabin** destination on the home screen.
2. Expand and upgrade the avatar cosmetics package into a larger, more realistic, more desirable 3D collection that looks good on all visible avatars across card games and other game-night surfaces.

This directive is not a suggestion. It is a production requirement.

======================================================================
1. HOME-SCREEN CABIN ENTRY
======================================================================

A new home-screen destination must exist:
- Label: **Visit the Cabin**.
- Placement: prominent and equal in importance to other top-level navigation actions.
- Visual treatment: 3D-style button/card matching the polished home-screen UI language.
- Behavior: opens the cabin aerial/dollhouse overview directly.
- Return behavior: exiting the cabin returns cleanly to the home screen.

The home screen must no longer require hidden flows or indirect navigation to reach the cabin feature.

======================================================================
2. COSMETICS NORTH STAR
======================================================================

Cosmetics should feel like collectible, premium, family-friendly 3D content — not flat stickers or cheap overlays.

The cosmetics package must look good:
- on lobby avatars;
- on in-game visible avatars around card tables/boards;
- on room visitors inside the cabin;
- in store/catalog previews;
- in reward/unlock presentation.

Cosmetics should remain readable at small size while still feeling like authored 3D items.

======================================================================
3. COSMETICS SCOPE
======================================================================

The upgraded cosmetics system should include a **large starter catalog plus expansion headroom**.

Recommended initial production target:
- 450+ cosmetic entries total across all cosmetic categories.

Suggested category structure:
- hats & caps;
- hair accessories;
- glasses & eyewear;
- earrings / jewelry;
- neckwear;
- tops / jackets / outerwear;
- full outfits / themed looks;
- gloves / wrist items;
- footwear;
- handheld props;
- back accessories / bags;
- novelty / seasonal items;
- achievement items;
- premium room-host / winner cosmetics;
- family-specific themed collections.

These cosmetics live **in addition to** the room/furnishing catalog and do not replace the room items.

======================================================================
4. REALISM / QUALITY RULES
======================================================================

Mandatory quality requirements:
- modeled or convincingly 3D-presented wearables, not paper-flat icons;
- believable materials such as cloth, denim, felt, leather, knit, wood, metal, beads, acrylic, plastic where appropriate;
- proper scale and fit on approved family avatars;
- visual compatibility with male/female/child-like/funny/goofy family avatar variants;
- accessories should not clip badly through heads, hair, shoulders, or card-table poses;
- silhouettes must stay clear in tabletop camera angles;
- items should still feel warm and family-friendly rather than hyper-fashion runway content.

======================================================================
5. WIN / BUY / GIFT LOOP
======================================================================

Cosmetics should be distributed via:
- arcade token purchase;
- arcade win rewards;
- achievement unlocks;
- seasonal rewards;
- gifting between players where allowed.

Players should be able to:
- preview item on avatar;
- equip/unequip easily;
- gift eligible items;
- trade in unwanted duplicates/items for arcade tokens where applicable;
- mix cosmetics with room-progression identity.

======================================================================
6. VISUAL PRESENTATION TARGET
======================================================================

The cosmetics store/catalog should match the premium cozy-cabin presentation style already approved for rooms.

Required presentation traits:
- large attractive thumbnails;
- grouped collections;
- rarity / source / token price markers;
- warm cabin-themed UI surfaces rather than flat spreadsheet grids;
- mix of mannequin/character previews and clean item cards;
- good desktop + mobile readability.

======================================================================
7. CROSS-GAME USAGE RULE
======================================================================

If a player equips a hat, jacket, glasses, prop, or outfit, the item should appear consistently on their avatar wherever that avatar is visible and technically appropriate, including tabletop/card games, cabin visits, and other avatar-forward modes.

If a specific high-motion or special-mode context requires simplified rendering, the simplified version must preserve recognizable identity.

======================================================================
8. ACCEPTANCE GATE
======================================================================

Before claiming W.15 is satisfied, verify:
- the home screen visibly includes **Visit the Cabin**;
- selecting it opens the aerial cabin view;
- the cosmetics catalog looks polished and premium;
- at least representative hats, props, wearable sets, and reward cosmetics preview well on avatars;
- the overall cosmetics presentation is strong enough to show to stakeholders without apology.
