# Black Family Game Night - W25 Production Asset Vertical Slice Constitution

Build date: 2026-08-31
Base runtime: GAME-NIGHT-STAGING-PHASE-W24-FLAGSHIP-EARRINGS-49
Status: HIGHEST-PRECEDENCE W25 CATALOG VISUAL DIRECTIVE

## 1. Purpose
W25 resets the visual production pipeline for the Cabin Shop and Avatar Shop. The existing 2,000 home + 2,000 wearable records remain authoritative for IDs, ownership, pricing, save compatibility, categories and collections. Generated SVG/PNG artwork is placeholder/concept art unless an item explicitly reaches the W25 Production Asset gate.

## 2. Locked art direction
- Stylized realism matching the approved family character imagery.
- Upscale rustic lodge: roughly 70% authentic warm cabin + 30% polished modern.
- Warm substantial timber, cognac leather, cream textiles, blackened metal, bronze, restrained stone and believable PBR material response.
- Never Roblox-shaped, cylindrical, generic mannequin, sticker-like or paper-doll art.

## 3. Gold-standard vertical slice
### Cabin
1. Kristen's Cozy Lodge Reading Chair - warm cognac leather, real sit interaction.
2. Live-Edge Nightstand - deep walnut/heavy timber top + black metal base.
3. Warm Table Lamp - linen shade + bronze base, real on/off light interaction.
4. Cabin Bed - deep walnut heavy timber frame + upholstered headboard.

### Avatar cosmetics
1. Cowboy Hat - dark brown ranch felt.
2. Aviator Sunglasses - gold frame + brown lenses.
3. Medium Hoop Earrings - smooth polished gold.
4. Aurora Face Glow upgraded into the W25 Soft-Glam Face Filter - restrained beauty/material effect rather than a pasted overlay.

## 4. Single-source production rule
A finished item has one authoritative production asset/implementation. Shop tile, selected preview, equipped/placed result and in-game runtime must derive from the same asset identity. A prettier disconnected thumbnail is forbidden.

## 5. Shop visibility rule
- Production-ready items may appear in the main shop.
- Unfinished generated placeholders remain preserved but move to Concept / Coming Soon presentation and cannot masquerade as final purchasable goods.
- Failed/internal assets are hidden from normal shoppers.

## 6. Avatar fit masters
- Kristen: use approved `kristen-approved-turnaround.png` as locked identity source.
- John: use approved `john-approved-turnaround.png` and production-skinned model where compatible.
- Kelsi: use the approved family lineup as the W25 provisional fit reference. Do not call Kelsi identity-final until a dedicated turnaround approval exists.

## 7. Hair/headwear behavior
Do not delete hairstyles to solve hat collisions. Use semantic head anchors plus hat-specific hair compression/tucking/clearance behavior while preserving recognizable hair silhouette.

## 8. Interaction requirements
- Reading chair: sittable interaction hook.
- Table lamp: toggle on/off with actual light/emissive state.
- Bed: place/rotate now; sleep/lie animation may follow after the visual slice passes.
- Side table: valid surface target for small decor.

## 9. Shop presentation
- Shop card image is rendered from the production asset where practical.
- Selecting a W25 production item opens a live rotatable 3D preview.
- Wearables offer an Equip Preview using the same production geometry/effect.
- Cabin objects offer a live 3D object preview and use the same production geometry when placed.

## 10. Mobile target
Baseline: mid-range phone approximately 2022 or newer. Desktop may use higher pixel ratio/shadow quality. Mobile must preserve silhouette/material readability without overheating or catastrophic frame loss.

## 11. Approval gates
1. Concept Approved
2. Production Asset Approved
3. Fit / Placement Approved
4. Shop Preview Fidelity Approved
5. Runtime Integrated
6. Actual Device Approved
7. Release Approved

Automated tests cannot substitute for visual approval.

## 12. Scale rule
Do not mass-produce the remaining catalog until all eight W25 vertical-slice items pass the actual-device visual gate. If the slice is weak, improve the slice rather than multiplying weak assets.
