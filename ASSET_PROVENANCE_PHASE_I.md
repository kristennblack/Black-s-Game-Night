# Phase I Asset Provenance

**Build:** `GAME-NIGHT-STAGING-PHASE-I-THREE-GAMES-07`

## Mexican Train

The dominoes, central station, train lanes, boneyard, racks and family-avatar open-train markers are rendered by the application using original Black Family Game Night HTML/CSS/tabletop components. No official commercial domino-game artwork is included.

## Skip-Bo

The 162-card deck uses original Black Family Game Night card faces, Wild treatment, backs, table, Stock, Discard and Building-pile presentation. No Mattel logo, packaging art or official Skip-Bo card artwork is included.

## Backgammon

The board, points, checkers, dice, cup and doubling cube are original dimensional HTML/CSS game components. Dice outcomes are generated by the authoritative room state and then presented by the visual settle animation.

## Shared assets

Existing family avatar images, player colours, profile selections, chat/reaction UI and shared application styling are reused from the Black Family Game Night project.

## Existing 3D assets

The package retains the previously integrated GLB assets for the existing 3D games. Those assets are technically audited separately in `FINAL_ASSET_AUDIT.txt`. This Phase I module does not claim to resolve the outstanding Prop Hunt final-art approval gate.

## External dependencies

Core Three.js and selected loader/helper modules remain externally CDN-loaded. This is declared as a staging warning rather than represented as locally packaged.
