BLACK FAMILY GAME NIGHT v1.0.10 - FULL REPLACEMENT

WHAT THIS VERSION ADDS
- Detailed rustic Cribbage pegboard with scores, starter, pegging count, counting phase, and a clearly labeled crib owner.
- Golf now shows a real stock pile + face-up discard; tap either to draw/take, then tap a grid card to swap. Stock draws may be discarded to flip a face-down grid card.
- Marbles & Jokers now has a full colored marble board with Camps, track, Home lanes, zoom/pan controls, tappable cards and tappable marbles.
- Draw-action games now show a physical deck on the table that can be tapped instead of relying only on action lists.
- Home and connecting screens have a richer Black Family Lodge / fireplace birthday scene for John Black.
- All v1.0.9 room switching, auto-sorted no-swipe hands, Trail Trouble, Prairie Pots, Last Haven, chat and avatar improvements remain.

UPDATE THE LIVE APP
1. Download and unzip the v1.0.10 full replacement ZIP.
2. Open GitHub Desktop and select Black-s-Game-Night.
3. Click Show in Explorer.
4. Keep the hidden .git folder. Do not delete the repository folder itself.
5. Copy everything INSIDE the v1.0.10 folder into the existing Black-s-Game-Night folder and replace the old project files.
6. Return to GitHub Desktop.
7. Summary: Black Family Game Night v1.0.10 - tabletop polish
8. Commit to main.
9. Push origin.
10. Cloudflare should deploy automatically. Do not reconnect Cloudflare or change its settings.
11. When deployment is green, open the main app URL and confirm the top bar says v1.0.10.
12. Create fresh rooms for Cribbage, Golf, and Marbles & Jokers for the first test.
