BLACK FAMILY GAME NIGHT v1.3.0-real3d

DEEP FAMILY PROP HUNT REBUILD

This is one substantial replacement package, not a chain of small launch versions. It keeps the existing Black Family Lodge and original games, but replaces the Prop Hunt pseudo-3D foundation with real WebGL 3D and a dedicated real-time multiplayer room.

WHAT TO TEST FIRST

1. LODGE -> FAMILY PROP HUNT
   - On the Lodge game shelf, press Play on Family Prop Hunt.
   - A private Prop Hunt room should be created automatically.
   - Use Copy Invite Link or Share Link and join from a second phone/browser.
   - Both players should appear in the same Prop Hunt lobby.
   - Choose family characters, press Ready, add computers if wanted, then start.

2. PAPA'S SHOP 3D FOUNDATION
   - Walk around a family character from front, side and behind. Their front must not billboard toward the camera.
   - Put one player behind a solid wall. The other player must not render through it.
   - Back the camera toward a wall. It must move closer instead of passing outside the building.
   - Walk into walls and closed windows. They must block movement.
   - Shoot toward a player behind a wall/window. The first world surface should take the ray hit.
   - Walk/run/turn/jump and test acceleration, gravity and landing.
   - Jump into a reasonable ledge/crate/tractor surface and confirm automatic mantling without a Climb button.
   - Try moving into another player and confirm the bodies separate instead of ghosting through each other.

3. CHARACTERS / DOGS / WEAPONS
   - Humans are actual 3D mesh bodies with front/back/side volume and articulated limbs.
   - Hunters carry a 3D prop-zapper attached to the hand rig.
   - Aim should zoom the camera and keep the crosshair/weapon direction readable.
   - Kelsi, Molly and Gunner use quadruped bodies, four legs/paws, heads/ears/tails and a backpack-mounted zapper.

4. PROP GAMEPLAY
   - Hider disguises use actual 3D prop meshes.
   - Health stays with the player when changing disguise.
   - Prop changes, 10 decoys and flash refresh behavior should match the locked rules.
   - Decoys are shot-ray surfaces.
   - In Family Chaos, caught hiders join the hunters.

5. OTHER GAMES
   - Confirm the original Lodge games still create/join/start normally.
   - Family Mystery and John's Birthday Seat should remain available.

CONTROLS
COMPUTER: WASD move, drag game view to look, Space jump/auto-mantle, Shift sprint. On-screen Aim/Shoot/Prop/Flash/Decoy/Lock controls remain available.
PHONE/TABLET: left joystick to move, drag the 3D view to look, Aim/Zoom, Shoot, Jump/Auto-Mantle, Sprint toggle, Prop, Flash, Decoy and Lock buttons.

DEPLOYMENT
This package has NOT been deployed automatically.

For the existing GitHub/Cloudflare app:
1. Keep the hidden .git folder in the existing repository.
2. Replace tracked project files with this package.
3. Commit, for example: Black Family Game Night v1.3.0 - real 3D Prop Hunt rebuild
4. Push main.
5. Existing Cloudflare Git deployment should run `npx wrangler deploy`.

Cloudflare settings:
Build command: blank / None
Deploy command: npx wrangler deploy
Root directory: /
Production branch: main

Wrangler now includes a v2 Durable Object migration for the new PropHuntRoom class. Do not remove the existing v1 GameHub migration.
