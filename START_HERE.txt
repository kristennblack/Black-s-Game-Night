BLACK FAMILY GAME NIGHT v1.2.0-launch
FULL REPLACEMENT LAUNCH CANDIDATE

This package builds on the tested Black Family Lodge project and keeps the original 18 multiplayer games while adding the newest family-game work.

INSTALL / UPDATE
1. Unzip this package.
2. Open the existing Black-s-Game-Night repository folder in Explorer/Finder.
3. KEEP the hidden .git folder.
4. Replace/overwrite the existing project files with EVERYTHING inside this package.
5. In GitHub Desktop, review the changes.
6. Commit with a message such as:
   Black Family Game Night v1.2.0 - Lodge launch update
7. Push origin to main.
8. Leave the existing Cloudflare connection/settings in place and allow the connected deployment to build automatically.
9. When deployment is green, hard-refresh the app once so the v1.2.0 service-worker cache takes over.

WHAT IS NEW
- Approved realistic Black Family Lodge home artwork.
- Moving fireplace flames, glow and embers layered over the approved home scene.
- Larger John-focused birthday Lodge presentation.
- Family Mystery with illustrated rooms, glowing movement blocks, family standees, suggestions, notes, accusations and optional computer detectives.
- Third-person 3D Family Prop Hunt tryout with family characters, visible prop-zapper, disguise/decoy/flash mechanics, 3-hit health, jumping, gravity, climbing and four family maps.
- John's Birthday Seat: a new third-person platform/jumping race with checkpoints, family-themed obstacles, computer racers and the birthday seat at the top.
- Character -> outfit selection flow with Back-to-character controls in the main multiplayer avatar flow and 3D-game selectors.
- Easy / Medium / Hard computer players available in all 18 original multiplayer games. Family Mystery, Prop Hunt and Birthday Seat also include computer-play options for solo testing/play.
- Every original multiplayer game can create an exact private-room invite URL. Game cards include Create & Share and room lobbies include Share Invite + Copy Link.
- Every new-game page includes a Share Game link that opens the correct game directly.

IMPORTANT MULTIPLAYER NOTE
- The original 18 games are the fully synchronized private-room multiplayer games.
- The three new games are included as playable launch tryouts with local/computer play. Their Share Game links open the correct game for another person, but their new 3D/local engines are not yet synchronized into the shared room state in this candidate.

FIRST TEST CHECKLIST
1. Open the home screen and confirm the approved cabin scene fills the Lodge hero area.
2. Confirm the fireplace flames/glow visibly move (unless Reduced Motion is enabled).
3. Create any original game using Create & Share and open the generated room link on a second device.
4. In a lobby, add Easy, Medium or Hard computer players and start a game with only one human.
5. Open Family Mystery and confirm illustrated rooms, glowing movement blocks, family standees and computer difficulty options.
6. Open Family Prop Hunt and test third-person movement, camera, jump/climb, shooting, disguise, decoy and flash actions.
7. Open John's Birthday Seat and test checkpoints, jumping/platforms and computer racers.
8. On a phone, verify touch targets and movement controls are comfortable.

Do not delete the .git folder or reconnect Cloudflare if the repository is already connected.
