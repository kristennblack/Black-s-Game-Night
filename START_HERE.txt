WHAT CHANGED IN v1.2.6

CRIBBAGE ON PHONES
- The Cribbage game table now uses the phone's actual small viewport height instead of forcing the older 760px-tall layout.
- The board, starter/crib zone, pegging display, and hand are compressed on narrow screens so more remains visible at once.
- GO is no longer buried in the sidebar below the game table.
- When GO is legal, a large GO button appears directly above your hand.
- Manual Score Hand / Continue counting actions use the same reachable phone action strip.
- Safe-area spacing is included for iPhone bottom controls.
- The crib discard SEND SELECTED CARDS control remains above the hand.
- End-of-hand scoring review and highlighted scoring combinations remain included.

CARD SORTING
All normal playing-card hands shown through the shared game UI now sort automatically:
1. Spades
2. Hearts
3. Diamonds
4. Clubs
5. Jokers / no-suit cards

Inside each suit the cards run:
Ace, King, Queen, Jack, 10, 9, 8, 7, 6, 5, 4, 3, 2.

This applies to the shared hand rendering used by the classic trick-taking games and extra card games such as Cribbage, Euchre, 31, Poker, President, Prairie Pots, Burn Logs, and other normal-card hands. Custom non-standard decks keep their own category grouping, with numeric ranks ordered high to low.
