# Black Family Game Night v3.0.0 Production3D Papa Alpha

This is the first **asset-first production 3D vertical slice**. It is intentionally focused on Family Prop Hunt -> Papa's Shop.

The goal is not to claim the entire game collection is now visually finished. The goal is to test a different production pipeline that can actually close the gap between the approved concept art and live gameplay.

## What is different from v2.1

High-attention visuals are now baked GLB assets instead of being created only from runtime Three.js primitive constructors.

### Production character assets

- John: `/public/models/characters/john.glb`
  - calibrated to the 1.82 m gameplay body
  - true front / side / back geometry
  - named articulated joints and hand/back sockets
  - plaid clothing geometry, boots, belt, hair and beard volume
  - curved approved-reference facial texture mapped to the real 3D head surface
- Gunner: `/public/models/dogs/gunner.glb`
  - calibrated to the 1.08 m large-dog gameplay profile
  - quadruped joint hierarchy and backpack socket
  - curved approved-reference facial/fur texture mapped to the real 3D head

The reference texture is NOT a camera-facing billboard. Walking behind either character still shows actual rear geometry.

### Production hero assets in Papa's Shop

- prop-zapper
- tractor
- old motorcycle
- Papa's tattered yellow chair
- stone fireplace
- workbench
- rolling tool chest
- loaded shelving

The visible GLB is swapped over the existing gameplay collider/fallback. Art replacement therefore cannot silently change wall, shooting, climbing or collision rules.

## Important limitation

John and Gunner are now baked GLB benchmark assets, but they are still project-authored stylized meshes generated from our production builder. They are **not yet final Blender-sculpted, continuously skinned studio characters with a full bespoke animation library**.

This build exists to answer the next practical question on the phone:

> Does the asset-first GLB approach materially improve likeness, silhouette and scene quality enough that we should continue the production pipeline?

If yes, the next step is to replace the benchmark John/Gunner meshes with fully sculpted/skinned source assets while keeping the same manifest, sockets, semantic animation and gameplay interfaces.

## Test Papa's Shop first

1. Start Family Prop Hunt.
2. Select **Papa's Shop**.
3. Use John as a hunter if possible.
4. Append `?qa3d=1` for one diagnostic run.
5. Check these views:
   - John front at normal camera distance
   - John side
   - John from directly behind
   - John aiming and firing
   - Gunner walking from the side and rear
   - shop doorway looking toward the tractor/workbench
   - fireplace/Papa-chair corner
   - motorcycle from the side
   - exterior looking back at the shop and rural horizon

## Pass/fail rules

A production asset does not pass because it loaded.

It passes only if:

- it is obviously more believable than the procedural fallback;
- John reads as John rather than Generic Man;
- Gunner reads as Gunner rather than Generic Dog;
- there is no front-facing billboard illusion from side/rear views;
- weapon and sockets stay attached through movement/aiming;
- GLB hero props align with the existing collision footprint;
- camera/walls/occlusion remain correct;
- performance remains usable on the actual phone.
