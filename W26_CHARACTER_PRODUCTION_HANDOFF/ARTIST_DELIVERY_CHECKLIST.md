# W26 Character Artist Delivery Checklist

## Every delivered character

- [ ] Matches the approved identity reference at front, 3/4, side and back views.
- [ ] Reads as stylized realism, not blocky procedural geometry.
- [ ] Uses believable hands/paws, feet, hair/coat and clothing volume.
- [ ] PBR materials are consistent and mobile-conscious.
- [ ] No missing textures or broken alpha.
- [ ] No negative scales.
- [ ] No non-finite transforms.
- [ ] GLB opens cleanly in an independent glTF viewer.
- [ ] LODs follow the supplied target ranges or document an approved deviation.
- [ ] Required sockets/anchors are present and named exactly.

## Kristen

- [ ] Identity and recognizable hairstyle preserved.
- [ ] Hair exists separately from the head/body.
- [ ] Natural hair profile provided.
- [ ] Cowboy-hat compression/tuck profile provided.
- [ ] Cap/beanie compression/tuck profile provided.
- [ ] Humanoid rig matches/bone-maps cleanly to the current animation contract.
- [ ] Shoulders/elbows/hips deform cleanly.
- [ ] Hat, glasses, earrings and face-mask sockets are present.

## Kelsi

- [ ] Small curly-coated dog identity preserved.
- [ ] Coat silhouette reads as curls without excessive transparent overdraw.
- [ ] Proper quadruped skeleton used.
- [ ] Ears, tail, neck and paws deform naturally.
- [ ] Hat socket allows ear clearance.
- [ ] Dog-specific glasses adaptation can be fitted without floating.
- [ ] Left/right ear charm sockets are present.
- [ ] Collar socket is present.

## John visual replacement

- [ ] Approved John identity preserved.
- [ ] Old segmented/blocky visible mesh fully replaced.
- [ ] Existing animation/bone naming retained where practical.
- [ ] New face-accessory sockets added.
- [ ] W26 cowboy hat and aviators fit without relying on portrait overlays.

## Delivery package

- [ ] `CHAR_KRISTEN.glb`
- [ ] `CHAR_KELSI.glb`
- [ ] `CHAR_JOHN.glb` when replacement is completed
- [ ] optional authoring source files
- [ ] texture source/export folder if not embedded
- [ ] a short export note listing tool/version and any deviations from the spec
