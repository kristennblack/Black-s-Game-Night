# W40 Meshy / Image-to-3D Prompt Pack

These prompts are starting points, not automatic approval. Always use the approved project reference images when the service allows image guidance.

## Papa's Shop hero bay
Create a game-ready stylized-realistic rural mechanic garage interior for a warm family game. Weathered timber framing, practical workshop construction, concrete floor with restrained oil/tire wear, large bright garage opening, authentic shelves and mechanic clutter zones. Strong dimensional silhouette, believable thickness, no toy-block proportions. UV unwrap and PBR textures. Avoid text/logos. Keep architectural surfaces modular and mobile-game appropriate. Output clean GLB-ready geometry at meter scale.

## Tractor
Create a recognizable older farm/mechanic tractor suitable for a stylized-realistic mobile game. Functional wheel/tire proportions, tread, painted metal body, exposed mechanical shapes, seat and steering details, moderate wear. Not photorealistic, not cartoon-blocky. Separate tires/body where practical. UVs and PBR base color, normal, roughness, metallic. Game-ready topology.

## Workbench + tool chest
Create a heavy mechanic workbench and rolling tool chest pair. Thick wood/steel work surface, drawers, handles, casters, believable construction and edge bevels. Warm worn workshop style, PBR wood/painted steel/bare metal variation. No brand logos. Distinct readable silhouette at third-person gameplay distance.

## Shelving + clutter kit
Create a modular mechanic-shop shelving kit with tires, buckets, gas cans, toolbox, small containers and safe family-friendly workshop clutter. Each prop must remain independently recognizable and useful as a Prop Hunt disguise. Avoid one fused decorative blob. Mobile-game topology and PBR textures.

## John block-in warning
Do not treat a one-click generated John as approved. If generating a block-in, use the approved John turnaround/reference and request a stylized-realistic adult male with correct overall proportions, short dark hair, short beard/stubble, red plaid shirt, jeans and work boots. Use the result only as a sculpt/retopology starting point. Final face, proportions, clothing and rig must be reviewed against the approved John reference before it can become `CHAR_JOHN_W40.glb`.
