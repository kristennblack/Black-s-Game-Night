HOW TO UPDATE THE EXISTING LIVE APP
1. Download and unzip this ZIP.
2. Open GitHub Desktop and select Black-s-Game-Night.
3. Click Show in Explorer.
4. KEEP the hidden .git folder in that repository folder.
5. Remove/overwrite the old project files with EVERYTHING INSIDE this package.
6. Return to GitHub Desktop.
7. Commit with: Black Family Game Night v1.1.0 tryout
8. Push origin.
9. Cloudflare should build automatically from the existing connection.
10. Open the app and confirm the top bar shows v1.1.0-tryout.1.
