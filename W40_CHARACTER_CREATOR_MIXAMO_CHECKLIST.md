# W40 John Character + Animation Checklist

## Character construction
- Start from the approved John references, not the current procedural/gameplay model.
- Match head-to-body proportion, shoulder width, torso length and overall silhouette before clothing polish.
- Preserve short dark hair, beard/stubble, red plaid shirt, jeans and boots.
- Keep hands large enough for stable two-hand weapon posing without exaggerated cartoon scale.

## Rig
- Humanoid skeleton with clean pelvis/spine/chest/neck/head chain.
- Stable clavicles/shoulders and twist behavior.
- Correct finger/hand orientation for the Prop Zapper grip.
- Foot bones and planted contact suitable for IK.
- No severe weight collapse at shoulder, groin or knee bends.

## Animation starting set
Idle, Walk, Run, Sprint, Start Move, Stop Move, Turn Left, Turn Right, Jump, Fall, Land, Mantle, Aim and Fire are the minimum gameplay contract. External animation libraries may supply starting motion, but retargeting and game-feel blending happen in the project.

## Approval boundary
Auto-rig success is not likeness approval. Animation success is not likeness approval. John only advances when the actual rendered model matches the approved character reference in the game camera.
