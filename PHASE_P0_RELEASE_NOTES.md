# Phase P0 Release Notes - Flagship Foundation 13

This package is the combined successor to Phase O. It preserves Black Gammon, Backgammon, Mexican Train, Skip-Bo and all existing app/game content while installing the new flagship 3D development governance.

## New in this package
- Master 3D Development Directive included verbatim from the user-provided directive.
- Actual Phase O repository audit and PH-CHAR-01 benchmark plan included.
- Locked Components Register added.
- Easy is now the default bot difficulty in the shared lobby, realtime Prop Hunt lobby, Birthday Seat and Family Mystery setup.
- Bot character/difficulty selectors in those special setup screens receive explicit light/readable styling to prevent black/unreadable selection boxes.
- Preservation regression test added for the recovered camera/Reset View, authored John path, muzzle shot revalidation, Papa Shop production seam and approved cabin assets.
- New build/cache identity prevents stale Phase O service-worker assets from masking the changes.
